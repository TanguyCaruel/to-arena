    No bookmarks bar? Use the console

    On cosmos.so, open the console (⌥⌘J in Chrome, Edge and Arc, ⌥⌘C in Safari, ⌥⌘K in Firefox), paste the script and press Enter. Only paste code you trust into a console: this script comes from this page and only reads your account.
